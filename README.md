# Basic Programming - Fall 2023

This repository contains coursework, assignments, and lab exercises from a Basic Programming course at University of Tehran (Fall 2023 semester), implemented in C programming language.

## 📚 Repository Structure

### Computer Assignments (CAs)
- **CA1** - Fundamental programming exercises including:
  - Temperature conversion (Kelvin/Fahrenheit to Celsius)
  - Decimal to binary converter
  - Change-making algorithm (vending machine simulation)
  - Physics simulation (fly collision problem)

- **CA2** - Tetris game implementation
  - Complete Tetris game with rotation mechanics
  - Score tracking system
  - Collision detection
  - Multiple tetromino shapes (4 different pieces)

- **CA3** - To-Do List application
  - User authentication (signup/login)
  - Board management system
  - Task organization with lists
  - File-based data persistence

### Laboratory Exercises (Labs)
- **Lab2** through **Lab9** - Weekly programming exercises covering:
  - Basic I/O operations
  - Control structures
  - Functions and procedures
  - Data structures
  - File handling

### Additional Directories
- **ExampleCodes** - Reference code samples
- **Test** - Test files and experimental code

## 🎮 Featured Projects

### Tetris Game (CA2)
A fully functional Tetris implementation featuring:
- Real-time gameplay with keyboard controls
- Shape rotation system
- Collision detection
- Progressive difficulty (speed increases)
- Score tracking

### To-Do List Manager (CA3)
A command-line task management application with:
- User account system
- Hierarchical organization (Boards → Lists → Tasks)
- CRUD operations for boards, lists, and tasks
- Persistent storage using files

## 🛠️ Technologies & Concepts
